# Contributing to Squire

Issues and pull requests are welcome. For substantial changes, open an issue describing the proposed behavior first.

Use stable Rust, Node.js 22, and pnpm 10. Install JavaScript dependencies with `pnpm install --frozen-lockfile` and develop with `pnpm dev`.

Follow existing code conventions, keep changes focused, and describe behavior changes in pull requests. Run appropriate formatting, typechecking, and linting commands before submitting.

By submitting a contribution, you agree to license that contribution under the project's [FSL-1.1-Apache-2.0](LICENSE.md) terms.
